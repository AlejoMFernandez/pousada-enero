# Pousada Enero · Maragogi

Sitio oficial (PT / ES / EN). HTML + CSS + JS sin dependencias, desplegado en Vercel.

- `_src/`: plantilla, textos (`i18n.json`) y `build.py`, que genera `index.html`, `es/` y `en/`.
- `js/data.js`: suítes y fotos (desde el motor de reservas).

Sitio desarrollado por [Alejo Martín Fernández](https://alejomfernandez.com.ar).
